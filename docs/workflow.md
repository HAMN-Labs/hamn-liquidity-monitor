# Workflow

## Правило ведения этапов
- Для каждого этапа используется отдельный backlog-файл в `docs/`.
- Выполняем задачи по чекбоксам сверху вниз.
- Если появляется новый scope или подзадача, дописываем ее в backlog текущего этапа.

## Фиксация прогресса
- Все завершенные задачи дублируются в `project_progress.md` с датой.
- Любые архитектурные изменения и принятые решения фиксируются отдельной строкой.
- Если задача частично выполнена, отмечаем это в `In Progress`.
